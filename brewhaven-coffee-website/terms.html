Terms of Use (Demo Project)

Please note: these are sample terms for a student project. They are not the legal terms of any real company.

1. About this website

Brewhaven Coffee Co. is a fictional brand. This website was built as a learning exercise to practice HTML, CSS and JavaScript. It is not affiliated with, endorsed by or connected to any real coffee company.

2. No real products or services

  • Menu items, prices and calories are sample data.
  • Store locations, addresses and opening hours are invented.
  • The rewards program does not award real stars or rewards.
  • Gift cards cannot be purchased and no payments are processed.
  • Sign-in and registration are simulated; no accounts exist.

3. Images and fonts

All illustrations in this project are original artwork created for it. The Inter font is open-source and free to use. If you replace images, make sure you have the right to use them (for example, photos from Unsplash or Pexels under their licenses).

4. Using this code

You may study, copy and change this code for learning. If you publish it online, keep the demo notices so visitors don't mistake it for a real business.

5. Questions

Read the project README or ask your instructor.
